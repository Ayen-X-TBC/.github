## عن المركز

المركز الموحد لإدارة وتطوير مشاريع **عاين بالتعاون مع شركة تطوير للمباني (TBC)**. يجمع مستودعات المشاريع والتوثيق التقني ومتابعة العمل في مكان واحد، من الفكرة إلى التسليم.

### مجالات العمل

- **البرمجيات والمنصات:** التطبيقات والخدمات والتكاملات.
- **البيانات والتحليلات:** خطوط معالجة البيانات والتقارير ولوحات المتابعة.
- **الذكاء الاصطناعي والأتمتة:** حلول تدعم فرق العمل وتحسن كفاءة العمليات.
- **التوثيق والتسليم:** المتطلبات والتصاميم التقنية وأدلة التشغيل.

### البداية مع أي مشروع

ابدأ بملف README داخل مستودع المشروع للتعرف على هدفه ومتطلبات تشغيله. استخدم Issues لمتابعة المهام وPull Requests لمراجعة التغييرات، ووثّق القرارات المهمة مع المشروع.

## About this hub

The central workspace for **Ayen projects in collaboration with Tatweer Buildings Company (TBC)**. This organization brings project repositories, technical documentation, and delivery tracking together in one place.

### Focus areas

- **Software & platforms:** Applications, services, and integrations.
- **Data & analytics:** Data pipelines, reporting, and dashboards.
- **AI & automation:** Solutions that support teams and improve operations.
- **Documentation & delivery:** Requirements, architecture, and operating guides.

### Working on a project

Start with the repository README for its purpose and setup instructions. Track work through Issues, review changes through Pull Requests, and keep technical decisions alongside the project.
